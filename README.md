## 🧠 Learning Approach

**Learn → Think → Code → Make Mistakes → Improve → Revise**

- One concept at a time.
- Practical coding challenges, not lectures.
- Attempt problems before seeing solutions.
- Understand WHY, not just HOW.
- Review mistakes and improve code quality.
- Connect concepts to real-world engineering.

**Weekly Commitment:** 6–7 hours

## 🤖 For AI Mentors

1. Read `master_context.md` and `progress.md`.
2. Continue from the last unfinished topic.
3. Review `learning_notes.md` for previous mistakes.
4. Teach one concept and assign one coding challenge.
5. Don't reveal solutions before my attempt.
6. Review my code critically, like a senior engineer.
7. Generate updated progress and learning notes after each session.

**Do not restart the roadmap unless explicitly requested.**
